# Simba Intelligence 26.2 — relationship to this Composer MCP

Context for anyone driving Composer alongside Simba Intelligence. Grounded in the
official v26.2.0 release notes (Confluence PJX/18483511372), Jira project PY, and a
live-verified 26.2.0 instance (2026-07-11). Full detail lives in
`isw-da/logi-si-docs/simba-intelligence/reverse-engineered/26.2-authoritative.md`.

## Why this matters here

- **SI 26.2 is now a Composer-aligned product.** All remaining Symphony integration
  was removed (PY-508); deployments are "Simba Intelligence with Composer", bundled or
  separate. Composer is the discovery/query layer beneath SI (`/discovery/api/...`, the
  v3 REST surface this MCP already speaks).
- **SI ships its own native MCP server** (FastMCP, OAuth2 PKCE, on service port 8001;
  the nginx sidecar was removed, PY-524). It is a *different, complementary* surface to
  this one: SI's MCP exposes governed natural-language querying (`get_data`,
  `search_data_sources`, `get_suggested_questions`, `get_field_statistics`) with
  per-user consent; this `composer-mcp` wraps the Composer authoring/REST API as tools.
  Use SI's MCP for "ask the data a question as a user"; use this for "build and manage
  Composer connections, sources, dashboards".
- **Composer feature flags now drive the SI UI** via a dedicated endpoint (PY-550) —
  `GET /api/v1/auth/features` on SI reflects Composer licence capabilities
  (e.g. `bi_features_disabled`).
- **Single sign-on with Composer** (PY-530) means SI and Composer share auth; SI's
  `managedUrl` value points auth at the Composer/managed URL.

## Practical notes for Composer work driven from here

- SI's MCP tool for finding sources is `search_data_sources(search_subject, max_sources)`
  — it replaced `get_data_sources` (PY-487). If any prompt or doc references the old
  name, update it.
- Switching an SI instance's embeddings model auto-wipes tenant-scoped vector indexes
  (PY-557), so Composer-side source changes that trigger a re-embed are cleaned up
  automatically.
- Related design: Confluence PJX/18246598721 "Simba Intelligence - Composer Embedding
  MCP App" (2026 embedding strategy).

This repo's Composer v25 REST patterns remain valid; SI 26.2 runs on a Composer 26.x
discovery layer, so confirm endpoint shapes against
`get_composer_openapi_spec` / the live `/discovery/api` when in doubt.
